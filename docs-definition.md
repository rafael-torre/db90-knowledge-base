# What documents do we want

## Discovery

Client Profile - Analysis of the people that we are going to interact with.
Company Story - Analysis of the company.
Competitive Analysis - Who are the main competitors.
Lean Canvas - Template to study the business. Opportunities and expectations.
Product Vision Board - Template to study the product.
Service Blueprint - Photo that represents the business and how it works (not the client, but what they are solving)
Metric Analysis - If they have metrics analyze them.
Personas — who are the users and stakeholders?
Domain Glossary - Words, terms specific to the business.

## Definition

Vision / Mission / Objective - Define these concepts for what we are going to build.
Problem Statement - What problems do we need to solve? 

## Ideation

Hypothesis|Brainstorming - How might we (solve problems from Problem Statement). Track which hypothesis and what made us decide.
Use cases | user flows — How do we solve these problems? For user X what does it do. 
Site Map - tentative architecture of the information and content.

Features — what needs to be built

Implicit requirements — what's assumed but not written down?
Gaps — what's missing or contradictory in the docs?
